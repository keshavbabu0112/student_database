A simple C-based student database management system that performs CRUD operations and stores records in a file.


# Student Database Management System

A simple **Student Database Management System** developed in **C** using **file handling**. The application allows users to store and manage student records through a menu-driven interface.

## Features

- Add new student records
- View all student records
- Search for a student
- Modify existing student details
- Delete student records
- Store data permanently using file handling

## Technologies Used

- C Programming
- File Handling
- Structures
- Functions
- Menu-Driven Programming

## Student Information

Each student record contains:
- Name
- Roll Number
- Marks

## How to Run

1. Clone the repository

```bash
git clone https://github.com/<your-username>/student_database.git
```

2. Navigate to the project directory

```bash
cd student_database
```

3. Compile the program

```bash
gcc *.c -o student_database
```

4. Run the executable

```bash
./student_database
```

> On Windows:

```bash
student_database.exe
```
